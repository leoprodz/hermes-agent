# How to teach pstack labs (for Leo)

**Audience:** any agent in a new or continuing chat when Leo says “vamos con Lab X”.

**Rule:** **Teach first. Apply only after he says apply / ejecuta / arrancamos.**

He learns pstack through **contrast**. Briefings that only describe the happy path fail him.

## Required briefing shape

(Same shape as the Lab D pre-brief he liked.)

Reply in **Spanish** if he wrote in Spanish. Adult plain language; one analogy max.

1. **Where this lab sits** — short table: prior labs → muscle each trained → this lab’s role.
2. **The contrast (required)**  
   - **Forma no recomendada** — without pstack / without the harness: what happens; where Leo is the bottleneck again.  
   - **Forma pstack** — with this lab’s skill/harness: what closes the loop.
3. **Name the pieces** he’ll see (`/poteto-mode`, `verify-hermes`, `control-hermes`, F-01, …) — one plain line each.
4. **Why this lab matters for understanding pstack** — one sharp sentence.
5. **What we will / won’t do when we apply** — lab scope; ignore later labs.
6. **Stop and ask** — “¿Arrancamos?” Do not implement in the same turn as the briefing unless he already ordered apply.

## After he says apply

Optional light narration: “sin el harness habría pasado X” vs “acabamos de capturar Y”. Keep short.

## Sources before briefing

- `notes/pstack-labs.md` — prompt + Done when

## Do not

- Jump straight into `/poteto-mode` on first “vamos con Lab X”
- Explain only the recommended path
- Stack jargon without a plain gloss on first use in that briefing
